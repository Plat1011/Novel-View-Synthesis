# Novel View Synthesis (NVS)

Соревнование: по 12 входным изображениям с 6 камер беспилотника в моменты `t0` и `t1`,
агрегированному лидарному облаку и позам камер — предсказать кадр заданной камеры
в промежуточный момент времени.

Метрика — PSNR, нормализованный в [0, 100]: `clamp(PSNR, 10, 30)` → линейно в [0, 100].

## Структура

```
Novel View Synthesis/
├── baseline/           # исходные файлы организаторов (RIFE+flow бейзлайн, visualize_sample.py)
├── src/                # наш код
│   ├── data.py         # загрузка sample-а, парс meta.json, лидара
│   ├── geometry.py     # проекции, варпы, depth
│   ├── pipelines/      # разные стратегии предсказания
│   └── submit.py       # сборка submission.zip
├── notebooks/          # эксперименты, EDA
├── scripts/            # одноразовые утилиты
└── kaggle/             # ноутбуки/конфиги для запуска на Kaggle
```

Датасет в репу не коммитим (см. `.gitignore`).
